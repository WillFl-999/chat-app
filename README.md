# Chat App

Aplicativo de chat em tempo real com Node.js, Express, Socket.IO, MongoDB e React.

## Estrutura do Projeto

- `backend/`: Servidor Node.js com Socket.IO e Mongoose.
- `frontend/`: Aplicação React com Vite e Socket.IO Client.

## Como executar

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Acesse http://localhost:5173
